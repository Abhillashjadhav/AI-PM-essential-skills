# Pairwise output-quality rubric

Use the same criteria for the baseline output (A) and candidate output (B).

- task success: directly solves the user's requested task
- correctness: claims are supported by the supplied context or reference answer
- completeness: includes the important information needed to finish the task
- constraint adherence: follows explicit format, audience, tone, length, and policy constraints
- first-pass usability: can be used without another model call or material human rewrite
