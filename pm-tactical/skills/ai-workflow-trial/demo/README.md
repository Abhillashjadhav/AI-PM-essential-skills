# Scripted synthetic CLI walkthrough

This lesson invokes the actual local `trial_kit.py` with bundled fictional
support-ticket records, checks process return codes, and presents values parsed
from its JSON output. It makes no model call and is not customer savings evidence.
Printed `YOUR_*` commands are adaptation recipes; executed commands use bundled
sample paths and a fresh temporary directory.

From this skill folder:

```bash
python3 demo/walkthrough.py --pause-seconds 0
```

The script clears the terminal between teaching steps. It is a CLI lesson,
not an accepted video recording or browser interaction capture. The rejected
legacy video renderer and its recording instructions are excluded from this
publication. Pending replay and recording artifacts are reviewed separately.

Use the [adaptation steps and blank templates](../README.md#adapt-this-to-your-own-workflow)
to collect your own task outcomes and active human-time records. Read customer
success and all measured effort together; a ratio alone names no winner.
